Format details

Tab-separated, team in the first column. Columns in order: team name, collector email, 1st visit feedback, 2nd visit feedback, 3rd visit feedback. One row per collector; the team name repeats on each row and groups them. The first header row (mentioning Collector email or visit feedback) is ignored. Blank feedback cells are skipped. Use Upload to open a .tsv or .csv file directly.

Timing

Times are in your browser's local clock, 24-hour. Leave a visit blank to send it as soon as the script runs. The tracker tab must stay open through all scheduled times — the script sits in its console and waits.

Submit

This page can't POST to the tracker directly — the browser blocks cross-origin submissions. The submit button below copies a ready-to-run script that you paste once into the tracker's own console, where the browser does allow it.
  1. Open the tracker in Chrome at ita.indivillage.com/Only_Google_Sheet_Business_Feedback/ (any page on that host works).
  2. Open the browser console. Windows: press F12. Mac: press ⌥ ⌘ J. Click the Console tab.
  3. Click Submit all below, switch to the tracker tab, paste in the console and press Enter.
  4. The script loads each team's business list, then runs the submissions — waiting for any scheduled times you set and the gap between submissions. Keep the tab open the whole time. Watch the console for live progress and a final count.
